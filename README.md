# Maxpharma Fullstack Application

This repository contains both the Backend and Frontend applications for Maxpharma.

## Project Structure

```
maxpharma/
├── backend/       # Express.js / TypeScript / MySQL REST API backend
└── frontend/      # Next.js 16 / TypeScript / Tailwind CSS web application
```

## Quick Start

### Backend
Navigate to the `backend` directory:
```bash
cd backend
npm install # or bun install
cp env.example .env # Configure environment variables
npm run dev
```

### Frontend
Navigate to the `frontend` directory:
```bash
cd frontend
npm install
cp env.example .env.local # Configure environment variables
npm run dev
```
